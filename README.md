# Passage Console

A single-file marine conditions dashboard for the crossing from West Vancouver Yacht Club to the Pasley / Ragged Islands.

## Hosting

The site runs directly on GitHub Pages from `boating-dashboard.html`. No local server, backend, serverless function, API key, or Python file is required.

## Live data

- Wind and waves: Open-Meteo
- Tides: Fisheries and Oceans Canada, Point Atkinson
- Map: Windy embed
- Skipper's read: local rules-based JavaScript

Open `boating-dashboard.html` through the published GitHub Pages URL.

This dashboard is decision-support only. Always check the official Environment Canada marine forecast and warnings before departure.
